# Ski Calculator — iPhone

Trade calculator with fractions, conduit bending, time cards and 230+ converters.

## Install

**Option 1 — Web app (no sideloading):** open the GitHub Pages link for this repo in **Safari**, tap **Share → Add to Home Screen**. It runs full-screen and works offline.

**Option 2 — Sideload the IPA:** download `SkiCalculator.ipa` from the **latest** release and install it with AltStore, SideStore, Sideloadly or TrollStore. With a free Apple ID, sideloaded apps must be refreshed every 7 days.

Every push to `main` rebuilds both automatically (GitHub Actions).
